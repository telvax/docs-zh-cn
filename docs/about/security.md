# 安全政策

## 受支持的版本

Telvax 目前处于早期 alpha 阶段。只有最新版本会收到安全修复；更早的版本不会打补丁，因此请在报告之前先升级。

## 报告漏洞

请通过 GitHub **私下**报告漏洞：打开仓库的 Security 标签页，选择 "Report a vulnerability"。请不要为安全问题创建公开的 issue、pull request 或讨论。

请尽量提供：受影响的版本（`telvax --version`）、你的操作系统、可以复现问题的最小 `.tvx` 程序或请求，以及你预期会发生什么。

## 你可以期待什么

* 我们的目标是在 **7 天**内确认收到报告，并在 **14 天**内告知你我们是否认定它为漏洞。这是一个小型项目，因此这些是目标，而不是保证。
* 已确认的漏洞会在新版本中修复，并在该版本发布之后公布安全公告。如果报告者希望署名，我们会予以致谢。
* 在你公开披露问题之前，请给我们合理的时间来修复。

## 范围

范围之内：`telvax` 和 `tvpm` 二进制文件、语言服务器、`telvax serve` 和 `telvax build --serve` 生成的 HTTP 服务器（请求处理、校验）、包管理器及其注册表客户端、安装脚本，以及 VS Code 扩展。

范围之外：你自己选择运行的程序的内容（解释器会运行给它的代码）、对开发服务器故意发送超大输入造成的拒绝服务，以及 Telvax 可能调用的第三方服务（Ollama、OpenAI、PostgreSQL）中的问题。
